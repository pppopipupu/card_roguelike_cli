# 魔法肉鸽卡牌游戏

基于 DND 5.5E 的文字回合制肉鸽卡牌游戏，无需 LLM。本仓库为无头游戏核心，AstrBot 插件与网页前端是独立仓库的客户端。

## 玩法

玩家扮演法师领主，沿分支地图推进：遭遇战、精英、随机事件、营地与商店。每回合分配动作（A）与附赠动作（BA），打出法术、部署护符、召唤随从并指挥它们作战；收集卡牌、强化卡组、控制血量，最终挑战关底 BOSS。

地图按网格探索，可移动、挖掘、传送、调查房间与拾取物品。阵亡会在本层留下尸体节点，其他玩家可发起冤魂战。支持 2~4 人联机，事件按单人/团队分级，队伍共享地图并投票结算。

## 指令

| 指令 | 说明 |
| :--- | :--- |
| `start` | 开始新游戏 |
| `status` / `s` | 生命、护盾、金币与战场状态 |
| `deck` / `bag` | 卡组与背包 |
| `p <序号> [目标]` | 打出手牌 |
| `m <格子> a/s <目标>` | 指挥随从攻击或使用技能 |
| `c <序号>` | 地图分支、事件与商店选择 |
| `end_turn` | 结束回合 |
| `potion`、`overview`、`tutorial` | 药水、总览与教程 |
| `help`、`changelog` | 指令帮助与更新日志 |
| `friend`、`team`、`trade` | 好友、组队与交易 |

指令支持中文别名，输入 `help` 查看完整列表。
